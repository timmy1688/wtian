## 解读方法
1. 主断依据：以 <卦象> 中的「主断经文」为核心判断吉凶倾向，「辅参经文」作补充；不要另选其他爻辞作为主断。
2. 本卦代表当下的处境，变卦代表事情的走向；没有动爻时只论本卦，不谈变化。
3. 借上下卦的取象描绘情境，例如上坎下震为「云雷屯」，再落到求问之事上。
4. 把经文中的吉、凶、悔、吝、厉、无咎等断语，转译为现代语境下的含义与分寸。
5. 紧扣 <求问> 中的具体问题，给出明确的倾向，避免模棱两可。
