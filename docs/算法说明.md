# 算法说明

本项目的原则是「代码算、模型讲」：凡是有确定规则的推算（排盘、起卦、取用经文、检索典籍）都由程序完成，大模型只在这些结果之上做解读。本文列出用到的全部算法、依据与代码位置。

## 一、代码分层

```
api/
├── suanfa/        算法层：纯计算，不依赖 Web 框架和大模型
│   ├── jichu.py       干支基础表（五行、藏干、十二长生、纳音、十神、合冲刑害）
│   ├── lifa.py        历法：四柱、节气、农历换算（唯一依赖第三方历法库的模块）
│   ├── jiben.py       基本推算：十神、十二长生、纳音、旬空、旺相休囚死
│   ├── wangshuai.py   五行力量、日主旺衰、扶抑喜用
│   ├── guanxi.py      干支合冲刑害、三合三会
│   ├── yunshi.py      大运、流年
│   ├── mingpan.py     汇总成完整命盘
│   ├── qigua.py       铜钱起卦、本卦变卦
│   └── quyong.py      动爻取用经文
├── dianji/        典籍层：古籍原文数据及其加载、检索
│   ├── zhouyi.json / zhouyi.py               《周易》卦辞、爻辞、大象、小象
│   ├── ditiansui.json / ditiansui.py         《滴天髓》原文与旧注
│   ├── qiongtong_baojian.json / qiongtong.py 《穷通宝鉴》十干十二月调候
│   ├── jiansuo.py     按命盘特征选取八字典籍原文
│   └── goujian.py     从维基文库重新生成两部八字典籍数据（维护用）
├── apps/          接口层：请求校验、提示词渲染、路由
│   ├── bazi/          /bazi/paipan、/bazi/fenxi(/stream)
│   └── zhanbu/        /zhanbu/cast_hexagram、/zhanbu/analyze_hexagram(/stream)
├── prompts/       提示词模块（通用规则 + 领域方法 + 关注方向）
├── utils/         大模型客户端、SSE、限流、日志、提示词组装
└── evals/         离线检查与在线评测
```

依赖方向只有一条：`apps → suanfa / dianji`。`suanfa` 中只有 `quyong.py` 读取 `dianji.zhouyi` 的原文，其余模块不读任何数据文件。

**命名约定**：
- 算法和典籍代码统一用拼音命名。函数是「动词 + 名词」，比如 `qiu_shishen`（求十神）、`pai_dayun`（排大运）、`pan_wangshuai`（判旺衰）、`qu_xiyong`（取喜用）；常量用大写拼音，比如 `DIZHI_CANGGAN`。
- 接口返回的 JSON 字段（如 `pillars`、`dayun`、`strength`）是对外约定，保持原样不改。

## 二、八字排盘

| 算法 | 规则 / 公式 | 函数 | 文件 |
|---|---|---|---|
| 出生时间解析 | 公历用 `YYYYMMDD HH` 解析；农历先转公历，二月三十这类日期在公历里不存在，所以不能用 strptime 解析 | `jiexi_shengri`、`nongli_zhuan_gongli` | `suanfa/lifa.py` |
| 四柱排盘 | 节气换月、立春换年，由 lunar_python 计算 | `pai_sizhu` | `suanfa/lifa.py` |
| 时辰 | 23–1 点为子时，之后每 2 小时一个时辰：地支序 = ⌊(时 + 1) / 2⌋ mod 12 | `qiu_shichen` | `suanfa/lifa.py` |
| 六十甲子序号 | 天干序 g、地支序 z 同奇偶，序号 n = (6g − 5z) mod 60 | `jiazi_xuhao`、`xuhao_jiazi` | `suanfa/jichu.py` |
| 十神 | 五行偏移 = (他干五行序 − 日干五行序) mod 5，0 同我、1 我生、2 我克、3 克我、4 生我；再按阴阳同异取「比肩/劫财、食神/伤官、偏财/正财、七杀/正官、偏印/正印」 | `qiu_shishen` | `suanfa/jiben.py` |
| 藏干 | 静态表：本气、中气、余气 | `DIZHI_CANGGAN` | `suanfa/jichu.py` |
| 十二长生 | 从该干的长生地支起数，阳干顺数、阴干逆数到目标地支 | `qiu_changsheng` | `suanfa/jiben.py` |
| 纳音 | 六十甲子每两组共用一个纳音：纳音序 = 甲子序 // 2 | `qiu_nayin` | `suanfa/jiben.py` |
| 旬空 | 一旬十干配十支，剩下两支为空亡：旬首地支之后第 10、11 位 | `qiu_xunkong` | `suanfa/jiben.py` |
| 旺相休囚死 | 月令当令者旺、我生者相、生我者休、克我者囚、我克者死 | `qiu_wangxiang` | `suanfa/jiben.py` |
| 五行力量 | 天干每字 1 分；地支按藏干拆分（1 个藏干 1.0，2 个 0.7/0.3，3 个 0.6/0.3/0.1）；月支 × 2 | `suan_wuxing_liliang` | `suanfa/wangshuai.py` |
| 日主旺衰（扶抑法） | 同党（比劫 + 印）占全局力量（不含日干自身）的比例 r：r < 0.28 身弱，< 0.38 偏弱，< 0.50 中和，< 0.60 偏强，其余身强。另给出三项依据：得令（月令本气属同党，或日主在月支为长生、临官、帝旺）、得地（地支藏有日主同五行）、得势（其余天干属同党） | `pan_wangshuai` | `suanfa/wangshuai.py` |
| 喜用忌神 | 身强、偏强喜克泄耗，忌生扶；身弱、偏弱反之；中和取力量最弱的一行 | `qu_xiyong` | `suanfa/wangshuai.py` |
| 干支关系 | 两两比对：天干五合（附合化五行）、天干相冲；地支六合、六冲、相刑、自刑（辰午酉亥）、相害；再看三合局（含中神的两支算半合）、三会方。分析大运、流年时只保留涉及它的关系 | `qiu_ganzhi_guanxi` | `suanfa/guanxi.py` |
| 大运 | 阳年男命、阴年女命顺排，反之逆排；从月柱起依次进退一位，共 8 步 | `pai_dayun` | `suanfa/yunshi.py` |
| 起运时间 | 出生时刻到下一个「节」（顺排）或上一个「节」（逆排）的天数 ÷ 3 = 起运岁数；交运日 = 出生时刻 + 岁数 × 365.2422 天 | `pai_dayun` | `suanfa/yunshi.py` |
| 流年 | 以立春换年；公元 4 年为甲子年，用来判断当前日期是否已过立春 | `pai_liunian`、`cha_dangqian_dayun` | `suanfa/yunshi.py` |
| 表面五行占比 | 八个字各计一次，算各五行的百分比，供前端图表使用 | `biaomian_wuxing_zhanbi` | `suanfa/mingpan.py` |
| 完整命盘 | 汇总以上结果；只传四柱、没有出生时间时不排大运 | `fenxi_sizhu`、`pai_mingpan` | `suanfa/mingpan.py` |

## 三、易经起卦

| 算法 | 规则 / 公式 | 函数 | 文件 |
|---|---|---|---|
| 三钱起卦 | 每枚铜钱字面计 2、背面计 3，三枚相加：6 老阴、7 少阳、8 少阴、9 老阳，概率依次为 1/8、3/8、3/8、1/8；老阴和老阳是动爻。自下而上摇六次 | `yao_yi_yao`、`qi_gua` | `suanfa/qigua.py` |
| 本卦与变卦 | 下三爻、上三爻各查八卦表，再用（下卦, 上卦）查六十四卦表，得卦名和通行本卦序；动爻阴阳互变即得变卦 | `pai_gua`、`qiu_jingua` | `suanfa/qigua.py` |
| 动爻取用 | 依朱熹《易学启蒙·考变占》，规则见下表 | `qu_jingwen` | `suanfa/quyong.py` |

| 动爻数 | 主断 | 辅参 |
|---|---|---|
| 0 | 本卦卦辞 | — |
| 1 | 本卦动爻爻辞 | 本卦卦辞 |
| 2 | 本卦上面那个动爻的爻辞 | 下面那个动爻的爻辞 |
| 3 | 本卦卦辞（贞） | 变卦卦辞（悔） |
| 4 | 变卦下面那个静爻的爻辞 | 上面那个静爻的爻辞 |
| 5 | 变卦唯一静爻的爻辞 | 变卦卦辞 |
| 6 | 乾用「用九」、坤用「用六」；其余卦用变卦卦辞 | 变卦卦辞或本卦卦辞 |

## 四、典籍检索与数据

| 内容 | 规则 | 函数 | 文件 |
|---|---|---|---|
| 《周易》原文 | 64 卦，每卦含卦辞、大象、六爻爻辞与小象，乾坤另有用九、用六 | `du_zhouyi`、`qu_gua` | `dianji/zhouyi.py` |
| 《穷通宝鉴》调候 | 按日干 × 月令（寅月为正月）取该月调候段；原书没有单列该月时，退回季节总论，再退回同季最近的月份并注明 | `qu_tiaohou` | `dianji/qiongtong.py` |
| 《滴天髓》条目 | 按（篇号, 原文开头）定位；篇名本身含断语时只标书名 | `cha_tiao`、`tiangan_lun` | `dianji/ditiansui.py` |
| 八字典籍检索 | 确定性选段，不用向量检索。按以下优先级选取，总长超过 1100 字时从低优先级开始舍弃，前两段始终保留：<br>1. 调候段；<br>2. 天干论里日干那一节；<br>3. 关注方向对应的一条；<br>4. 强弱对应的衰旺论或中和论；<br>5. 生于亥子丑、巳午未月时加寒暖论；<br>6. 原局有地支相冲时加地支论 | `jiansuo_dianji` | `dianji/jiansuo.py` |
| 典籍构建 | 处理步骤：<br>1. 抓取维基文库原文；<br>2. 用 OpenCC 繁转简，并校正录入错字；<br>3. 去掉例命表格；<br>4. 逐句摘取，遇到宿命断语（寿夭、疾病、克夫克妻、贫贱、僧道等）就从该句截断；<br>5. 《穷通宝鉴》另截掉科甲、富贵一类断语，只留调候用神；<br>6. 校验天干论覆盖十干、十干四季都有段落 | `goujian_ditiansui`、`goujian_qiongtong`、`zhaiqu` | `dianji/goujian.py` |

数据字段：

| 文件 | 结构 |
|---|---|
| `zhouyi.json` | `{卦序: {guaxu, guaming, jianming, guaci, daxiang, yao: [{yaoming, yaoci, xiaoxiang}], yong?}}` |
| `ditiansui.json` | `{yuanxinxi, pian: {篇号: {pianming, tiao: [{yuanwen, zhu, jieduan}]}}}` |
| `qiongtong_baojian.json` | `{yuanxinxi, rigan: {天干: {jijie: {春夏秋冬: {biaoti, wen, jieduan}}, yuefen: {1-12: {...}}}}}` |

`yuanxinxi` 是元信息，记录书名、版本、来源链接、授权说明、构建日期和过滤词。

## 五、大模型部分

| 环节 | 做法 | 位置 |
|---|---|---|
| 系统提示组装 | 通用规则 + 领域方法 + 关注方向，静态拼接，可以命中 DeepSeek 的上下文缓存 | `utils/prompting.py`、`prompts/` |
| 用户消息 | 命盘渲染为 `<命盘>`，检索到的典籍渲染为 `<典籍>`，卦象与取用经文渲染为 `<卦象>`；用户自由输入会被清洗，并截断到 60 字 | `apps/bazi/prompt.py`、`apps/zhanbu/prompt.py` |
| 流式输出 | SSE，带 `Cache-Control: no-transform`，防止代理缓冲 | `utils/streaming.py` |

## 六、验证

| 命令 | 内容 |
|---|---|
| `./wtian.sh check` | 离线检查，包括以下几项：<br>• 随机 1000 个命盘，逐项与 lunar_python 内置实现对照（藏干、十二长生、纳音、十神、旬空、大运干支与起运年）；<br>• 《周易》数据完整性；<br>• 动爻取用规则；<br>• 典籍检索：十干 × 十二月全覆盖、引用都能找到、不含禁用词、不超长度预算；<br>• 提示词组装 |
| `./wtian.sh eval [--judge]` | 在线评测：固定案例调用真实模型，检查篇幅、小节、禁用词、编造的干支、典籍引文是否逐字出自原文；可加 `--judge` 让模型评分 |
